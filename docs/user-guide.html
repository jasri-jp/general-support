    どうやって使うの？：利用方法

    SPring-8は利用申請手続きを通して利用できます。 申請が採択された利用は「利用研究課題」として扱われます。 「利用研究課題」は利用形態によって「課題種」が設定されています。 利用形態は、大きくは「得られた成果を公開する場合／成果非専有利用」と「成果を公開しない場合／成果専有利用」の２種類に分類されます。

    • 成果非専有利用/成果専有利用について
    このそれぞれの利用形態で、使い方に対する多様なニーズに対応する「課題種」が設けられています。 各課題種の主な違いは申請された課題の採否の審査方法と利用料金の設定です。

    課題申請

    申請者の応募資格について

    申請者はSPring-8 User Informationサイト「 応募資格に関して」に記載されている資格を満たしていることが必要です。

    放射線従事者登録について

    上記の応募資格で求められている「放射線従事者登録」は課題が採択されて実験を実施するまでに手続きが完了している必要があります。所属されている事業所によっては、手続きに時間がかかる可能性があります。放射線従事者登録の手続き方法については「 詳細：放射線作業者登録申請書【様式5-1】 」に説明がありますので、利用申請御検討時に早めにご確認ください。

    事前検討

    SPring-8の利用を検討される際、まずご自身の研究テーマ（課題解決）にSPring-8利用が分析手法として適しているかを検討していただく必要があります。 その上で、適していると判断されたら、具体的な利用実験の技術的内容およびそれを実施するビームラインを検討することになります。 これらの技術的検討については、お問合せください。

    課題種、利用時期の決定

    具体的な実験内容の案ができましたら、利用する課題種、利用時期を決定します。課題種によっては対応していないビームラインがありますので、ご注意ください。

    まず課題種については以下のページでご確認ください。

    • 課題種

    要確認情報

    • 課題種ごとの利用料金
    • 成果非専有課題を選択した場合の成果公開方法
    • 成果非専有課題/成果公開優先利用課題で成果準公開利用を選択した場合の成果公開方法

    利用時期について、利用研究課題の募集は上記のページで説明されているように、課題種によって「定期募集」と「随時募集」の２種類があります。 ご自身の研究テーマのスケジュールに合わせて使い分けてください。

    定期募集の課題種については利用期と、各利用期毎の課題募集の締め切りが設定されています。 以下のホームページで確認してください。

    • 利用期および各利用期の申請締め切り
    • 現在募集中の利用研究課題の募集要項

    一般課題、成果公開優先利用課題、等

    成果非専有利用の課題種を選んだ場合、課題審査を行う希望審査分野を選ぶ必要があります。産業利用分野で審査されることを希望される場合、「産業利用（IND）」を申請の際に選択してください。

    • 希望審査分野表

    注意：希望審査分野を「産業利用（IND）」とする場合

    希望審査分野を「産業利用（IND）」として成果非専有利用の課題種で申請される場合、審査基準、申請条件、等で注意するべき点がありますのでSPring-8 User Informationサイトの以下の情報をチェックしてください

    • 希望審査分野を産業利用とする一般課題・大学院生提案型課題について

    成果専有測定代行（定期募集）

    ビームラインスタッフがユーザーに代わって測定を行う成果専有利用課題です。 手順としては事前にビームラインスタッフとご相談いただいて測定内容（実験条件、測定試料数、等）を決めていただきます。 ビームラインスタッフはユーザーから測定試料をお預かりして事前相談で決定した測定内容に基づき、測定を行います。 測定後、お預かりした測定試料と測定データをユーザーにお返しします。基本的にデータの解析は測定実施内容に含まれません。 ユーザーの測定現場への来所・立ち会いは任意で、測定試料は郵送が可能なものであれば事前に郵送することで来所なしで実施可能です。
    成果専有測定代行は以下のビームライン・装置で実施しています。

    • BL14B2 XAFS
    • BL19B2 粉末X線回折
    • BL19B2 小角X線散乱
    • BL46XU 硬X線光電子分光
    • BL28B2 高エネルギーX線CT

    利用方法の詳細は 各利用期の測定代行課題募集の募集要項で確認してください。

    事前相談申込の窓口は以下のリンクをご参照ください。

    成果専有時期指定課題

    定期的な募集の締切によらず随時申請を受け付ける成果専有利用課題です。 利用可能な日程は、各ビームラインの確定している利用スケジュールの空き時間を利用しますので、事前のビームラインスタッフとの相談の際に確認してください。
    一部のビームラインでは１時間単位（上限４時間）の「時間単位利用」も受け付けており、利用を検討されている実験の技術的可能性の確認や測定条件の検討などのテスト実験にも活用可能です。

    申請内容案の作成

    実験内容、利用する課題種、利用時期が決まりましたら申請書の文案を作成します。課題申請の方法は後述するWEB申請ですが、まず各課題種用に用意されている 下書きフォーマットを使って下書きを作成することをお勧めします。この下書きはビームラインスタッフと事前相談する際にご各様ください。

    申請

    課題申請は「 SPring-8 User Information」サイトから行います。

    ユーザー登録

    この申請を行うにはSPring-8ユーザー登録を行う必要があります。 ユーザー登録すると、「SPring-8 User Information」のページのマイページにログインできるようになり、このマイページから課題申請を行います。 ユーザー登録がまだの方は以下のURLから登録手続きを行ってください。登録は無料です。

    • 新規ユーザー登録

    申請

    ユーザー登録が完了し、「SPring-8 User Information」のページのマイページにログインできたら、以下の手順で課題申請を行なってください。

    • 利用研究課題申請のWeb操作手続き

    課題実施

    利用研究課題申請を行なった後、審査で採択されると、その旨の連絡が事務局よりメールで通知されます。 その後、以下の手続きが必要になります。

    実験実施日程の調整

    採択された利用研究課題が決まると、各ビームラインで各課題の実施日程が調整されます。 この日程調整はビームライン毎に手順が違いますので、実施予定のビームラインのスタッフの指示にしたがってください。 日程が確定しましたら、事務局よりメールで連絡されますので、確認してください。

    実験実施までに行う手続き

    実験実施日程が確定しましたら、その日程までに所定の期限までに提出する書類等の手続きが必要になります。以下のURLを参考に手続きしてください。

    • 実験責任者（申請者）が行う手続き
    • 共同実験者が行う手続き

    実験実施の事前相談

    実験実施に関わる技術的な事前相談は実施予定のビームラインスタッフにご連絡ください。 各ビームラインスタッフの連絡先はSPring-8 のホームページの「 ビームライン一覧」の担当者の欄でご確認ください。

    実験前準備のための来所手続き

    実験実施前に来所して持ち込み装置等の事前調整作業が必要な場合があります。
    その場合の来所手続きについてはSPring-8 User Informationサイトの「 詳細：実験装置調整のための来所手続きについて」でご確認ください。
