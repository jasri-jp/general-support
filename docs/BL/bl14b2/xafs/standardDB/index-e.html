BL14B2 XAFS Standard Sample Database (BENTEN version)
Overview

The BL14B2 XAFS Standard Sample Database collects XAFS spectral data of standard samples measured at BL14B2, organizes them systematically, and provides them. The XAFS Standard Sample Database contains XAFS spectral data, measurement conditions, and sample information. All of the data in the XAFS Standard Sample Database can be downloaded from the browser of a personal computer. Currently, the XAFS Standard Sample Database contains XAFS spectral data of 45 elements and 866 samples (as of 2.27.2026). The XAFS Standard Sample Database uses the SPring-8 experimental data transfer system BENTEN, which can manage and store various experimental data, including metadata such as experimental conditions.
