ちょっと便利なコマンド

＊注意点：
１．BLWSをコントロールしているコマンドはCtrl-Cで中断させないこと。

２．MBS,DSSのコントロールを含むコマンドはPLCでMBS,DSSコン トロールを　 LOCAL ONLY　→　LOCAL＋REMOTE　に切り替えておくこと（１．④MBS,DSS遠隔操作コマンドの項を参照）

チェックコマンド
チェック項目 動作 コマンド パラメータ　／　アクション
ダークカウント 自動チェック chk_dark [カウント時間(sec)]
自動的にDSSを閉めてダークをカウントする。終わったらDSSを元の状態に戻す
ビームダンプ メールでお知らせ chk_bmdump [メールアドレス]
／現在のリングカレントおよびMBSの状態をチェックし、もしビームがダンプしていたら引数のメールアドレスにビームダンプを知らせるメールを送る。
