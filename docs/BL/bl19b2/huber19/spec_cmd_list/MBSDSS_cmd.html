MBS,DSSコントロール ／LOCAL ONLY　→　LOCAL＋REMOTEの切り替え方

１．PLC左下のスイッチ（写真左下の赤丸）をタッチする。（表示：LOCAL ONLY）
２．出てきたメニューの「LOCAL＋REMOTE」（写真赤丸）をタッチする。
３．ボタンの色が赤色に変われば「ENTER」（写真赤丸）をタッチする。
４．PLC画面左下のスイッチの表示（写真左下の白丸）が赤く代わり、表示が「LOCAL＋REMOTE」に変わればOK。
